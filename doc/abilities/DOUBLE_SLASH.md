# Double Slash

Dagger 전용 어빌리티. 다음 기본 공격 한 번을 독립적인 두 번의 타격으로 대체한다.

- 캐릭터 창의 Abilities 탭은 액티브·패시브 스킬을 아이콘으로 표시하고 마우스 오버 시
  설명을 보여준다. 낚시 등 숙련도와 경험치는 기존 Skills 탭에 표시한다.
- Abilities의 아이콘을 기존 1–0 퀵슬롯으로 끌어 등록한다. 인벤토리와 같은 `startDrag`,
  `DragGhost`, `quickslotAt`을 사용하며, 브라우저 기본 드래그는 사용하지 않는다. 슬롯을 누르면 다음
  기본 공격 한 번을 2연격으로 대체하며, 발동 전에 다시 누르면 예약을 취소한다.
- 주무기의 `weaponType`이 `dagger`일 때만 사용할 수 있다. 클라이언트가 사용을
  제한하고 서버도 장착 타입을 검증한다. 클래스나 개별 아이템 ID로 제한하지 않는다.
- 각 타격은 기본 단검 공격과 동일한 명중 판정과 피해 계산을 독립적으로 수행한다.
  무기 주사위, 힘 보정, 강화 보너스를 포함한 피해의 100%씩 두 번이다.
  전투 로그도 `Double Slash 1/2`, `Double Slash 2/2`로 나누어 각각의 주사위 결과를 표시한다.
- 타격은 시작 후 190ms와 425ms, 동작은 820ms, 재사용 대기는 10초다.
  기본 공격과 같은 공격 간격을 공유하므로 직후에 기본 공격을 추가할 수 없다.
  현재 애니메이션과 타격 시점은 고정이며 공격 속도에 비례해 재조정하지 않는다.
  시간 설정은 `data-src/player_anim_timing.csv`에서 공유한다.
- 서버는 타격마다 생존, 위치, 사거리, 장애물, 대상 상태와 같은 단검 인스턴스가
  계속 장착되어 있는지 확인한다. 발동 후 새 이동 명령·무기 교체·탑승·접속 종료 시
  남은 피해가 취소된다. 발동 전 접근 이동을 서버가 마무리하는 것은 취소 조건이 아니다.
  1타로 대상을 처치해도 820ms 동작과 검 궤적은 끝까지 재생한다. 2타는 주사위를 굴리지 않고
  `SKIPPED — target defeated`로 기록하며 추가 피해나 보상은 발생하지 않는다.
  사거리 이탈 등 타격 전제 조건이 깨진 경우에도 실제 명중 실패와 구분해 생략 사유를 기록한다.
  발동 후 취소되어도 재사용 대기는 유지된다.
- 재접속 시 서버의 `AbilityCooldowns`에 남은 단검 쿨타임을 포함하여 퀵슬롯 표시를 복원한다.
  쿨타임은 캐릭터별로 보존하며, 만료 전 요청은 서버가 거절한다. 다른 캐릭터의 쿨타임과 공유하지 않는다.
- A안의 짧은 청록색 칼날 잔상을 사용하며 타격 결과와 피해 표시는 각각 전달한다.
