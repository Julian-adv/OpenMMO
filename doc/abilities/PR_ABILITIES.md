# Add Guardian Ward, Double Slash, Radiance, and True Aim abilities

기존 아이템 퀵슬롯을 함께 사용하는 어빌리티 4종을 추가합니다. 무기·방패의 실제 장착 타입을 기준으로 사용 조건을 검증하고, 서버에서 피해·버프·지속시간·재사용 대기시간을 관리합니다.

대상 지정이 필요한 True Aim은 몬스터 위에 마우스를 올린 상태에서 단축키로 먼저 시전할 수 있습니다. 대상을 클릭하면서 일반 공격이나 추적이 시작되어 표식을 걸기 전에 공격하는 문제를 피할 수 있습니다.

## 어빌리티 구성

| 어빌리티 | 장착 조건 | 동작 및 효과 | 범위·지속시간 | 재사용 대기 |
| --- | --- | --- | --- | --- |
| **Guardian Ward** | 주무기 Sword 또는 Mace + 보조 손 Shield | 자신과 주변 파티원의 Guard +10% | 같은 층, 반경 20 m / 60초 | 45초 |
| **Double Slash** | 주무기 Dagger | 다음 기본 공격을 독립적인 100% 피해 2회로 대체 | 기존 단검 공격 사거리 / 동작 0.82초 | 10초 |
| **Radiance** | 모든 무기 및 맨손 | 주변을 밝히는 자기 자신용 토글 버프 | 기존 횃불과 같은 조명 범위 / 120초 | 켜기·끄기 각각 0.8초 |
| **True Aim** | 시전 시 주무기 Bow | 지정 대상에 대한 자신의 공격이 반드시 명중 | 현재 Bow 사거리 10 m / 5초 | 10초 |

### Guardian Ward

- 시전 순간 같은 층의 반경 20 m 안에 있는 살아 있는 파티원과 자신에게 적용합니다. 파티가 없어도 자신에게 사용할 수 있습니다.
- 기본 Guard, 착용 장비 Guard, 방어구 강화 보너스의 합에 10%를 추가합니다. 추가량의 소수점은 버립니다. 예: `31 → 34`, `48 → 52`.
- 재시전이나 다른 파티원의 동일 버프는 지속시간을 60초로 갱신하며 중첩하지 않습니다.
- 시전 후 범위를 벗어나거나 장비를 바꿔도 남은 버프를 유지합니다. 장비 변경 후에는 현재 장비의 Guard를 기준으로 계산합니다.
- 옅은 금빛의 방패 문양이 적용 대상 앞에 동시에 나타납니다. 효과음에 맞춘 짧은 크기 변화와 섬광을 사용하며, 발동 연출은 약 1초 동안 재생됩니다.
- 주변 사용자에게 서버 발동 이벤트를 전달합니다. 효과음은 기존 SFX 설정을 따르며, 같은 층의 시전자 주변 20 m에서 재생됩니다.

### Double Slash

- 퀵슬롯으로 다음 기본 공격을 예약하고, 발동 전에 다시 누르면 예약을 취소합니다. 기본 공격과 공격 간격을 공유합니다.
- 무기 피해 주사위, 힘 보정, 강화 보너스를 포함한 기본 단검 공격의 **100%씩 두 번** 계산합니다. 각 타격의 명중과 피해 주사위는 독립적입니다.
- 타격 시점은 시작 후 **190ms와 425ms**, 전체 애니메이션은 **820ms**입니다. 시간 설정은 `data-src/player_anim_timing.csv`를 공유합니다.
- 기본 공격 한 번의 공격 주기 안에서 두 번 타격합니다. 현재 연출·타격 시점은 고정 820ms 기준이며, 공격 속도에 비례해 애니메이션 전체를 재조정하지는 않습니다.
- 각 타격 전에 서버가 생존·사거리·장애물·대상 상태·장착 단검 인스턴스를 다시 확인합니다. 발동 후 새 이동 명령, 무기 교체, 탑승, 접속 종료 등으로 조건이 깨지면 남은 피해를 취소합니다.
- 전투 로그는 `Double Slash 1/2`, `Double Slash 2/2`로 분리합니다. 1타에 대상이 죽어도 애니메이션과 칼날 잔상은 끝까지 재생합니다. 이 경우 2타는 추가 주사위·피해·보상 없이 `SKIPPED — target defeated`로 기록합니다.
- 실제 명중 실패와 조건 불충족으로 생략한 타격을 구분합니다. 발동 후 취소되더라도 이미 시작된 재사용 대기는 유지합니다.
- 제공된 Inward/Outward Slash 애니메이션을 결합하고, 선택한 A안의 짧은 청록색 칼날 잔상을 적용합니다. 주변 사용자는 서버 이벤트에 따라 같은 동작을 재생합니다.

### Radiance

- 켠 시점부터 120초 동안 유지되며, 같은 퀵슬롯으로 직접 끌 수 있습니다. 켜기와 끄기 모두 서버에서 0.8초 재사용 대기를 적용합니다.
- 시전 시 빛 구슬이 몸 주위를 한 바퀴 돌고 0.8초 안에 사라집니다. 유지 중에는 주변 조명만 남습니다.
- 기존 횃불의 광원 범위·감쇠·그래픽 품질 설정을 재사용합니다. 횃불과 동시에 사용해도 밝기를 중복 합산하지 않으며, 물 표면에도 같은 조명을 반영합니다.
- 조명은 켤 때 부드럽게 밝아지고, 끄거나 만료되면 잦아듭니다. 자연 만료에는 추가 재사용 대기를 적용하지 않습니다.
- 켜짐·꺼짐·만료·사망 상태를 주변 클라이언트와 공유합니다. 플레이어 스냅샷에도 조명 상태를 포함해 나중에 접근한 사용자에게 표시합니다.
- 피해나 Guard를 변경하지 않으며 Guardian Ward와 함께 유지할 수 있습니다.

### True Aim

- **유효한 마우스 오버 대상 우선, 없으면 현재 지정된 공격 타겟**을 사용합니다. 죽었거나 제거된 대상은 제외하고, 둘 다 없으면 대상 지정 안내를 표시합니다.
- 대상 선택이나 시전 요청 자체로 일반 공격·자동 추적을 시작하거나 기존 공격 타겟을 바꾸지 않습니다.
- 서버가 장착 Bow의 사거리, 같은 층, 원거리 시야를 검사합니다. 사거리 밖이면 `Target is too far away.`를 표시하며 표식과 재사용 대기를 적용하지 않습니다.
- 표식 대상에 대한 **시전자 본인의 공격만** 반드시 명중합니다. 피해 주사위·화살 피해·능력치·강화 보너스와 공격 시 사거리·장애물·화살·공격 간격 검사는 기존 계산을 따릅니다. 표식 시전 자체는 화살을 소비하지 않습니다.
- 시전 후 무기를 바꿔도 남은 표식 효과는 유지합니다. 다른 대상을 공격하면 일반 명중 판정을 사용합니다.
- 옅은 붉은 조준 문양이 대상 머리 위에 나타나고 주기적으로 커졌다 작아집니다. 표식과 대상 ID는 시전자에게만 전달하며, 다른 파티원이나 주변 사용자에게 표시하지 않습니다.
- 5초 종료, 대상 사망·제거, 시전자 사망·접속 종료·층 변경 시 해제합니다. 종료 시의 시각적 잔상에는 명중 효과가 없습니다.

## 공통 UI와 입력

- 캐릭터 창의 **ABILITIES**에 아이콘 형태의 어빌리티 목록을 추가합니다. **SKILLS**는 낚시 등 기존 숙련 스킬 목록으로 유지합니다.
- 아이콘을 기존 **1–0 퀵슬롯**에 드래그하여 등록합니다. 인벤토리의 포인터 드래그, `DragGhost`, 슬롯 판정 코드를 재사용하여 브라우저 기본 드래그의 금지 커서를 피합니다.
- 목록과 퀵슬롯은 공용 기술 툴팁을 사용합니다. 이름·설명·효과·장착 조건·시간 정보를 인벤토리 아이템 설명과 같은 형식으로 정리합니다.
- 퀵슬롯에 예약·활성 상태와 재사용 대기를 표시합니다. 적용 중인 버프는 좌측 상단 레벨·허기 표시 옆에 아이콘과 남은 시간으로 표시합니다.
- 한시적인 버프 상세는 **STATUS 하단**에 배치하여 만료될 때 기본 상태 정보의 위치가 바뀌지 않게 합니다.
- 장착 조건을 만족하지 않을 때의 메시지를 `Cannot use {ability name}.`으로 통일합니다.
- 대상 지정형 버프·디버프는 어빌리티의 `target: 'monster'` 설정으로 마우스 오버·지정 타겟 선택 규칙을 공유합니다. Double Slash는 다음 기본 공격을 대체하는 예약 방식을 사용합니다.
- 이번 범위에는 별도의 어빌리티 습득·레벨업 시스템을 추가하지 않습니다. 현재 등록된 어빌리티를 표시하고 사용 시 장착 조건을 검사합니다.

## 아이템 분류 변경

Guardian Ward의 방패 조건을 장착 슬롯만으로 판단하지 않도록 명시적인 타입을 추가합니다.

- 아이템 정의에 **`armorType: 'shield'`**를 추가하고 Wooden Shield와 Raven Shield에 지정합니다. 서버도 off-hand 방어구인지 검증합니다.
- 같은 보조 손 슬롯에 들어가는 Torch는 방패로 인정하지 않습니다.
- **`short_sword`를 `sword`로 통합**하여 Goblin Sword와 Small Sword를 Sword 계열로 분류합니다. Dagger와 Great Sword는 별도 타입을 유지합니다.
- CSV 데이터, 서버·클라이언트 타입과 표시, 관련 테스트를 함께 변경합니다. 아이템 분류 수정도 이 어빌리티 PR의 범위에 포함합니다.

## 서버·네트워크와 상태 수명

- 서버가 발동 조건, 피해, 버프 대상, 지속시간, 재사용 대기를 판정합니다. 사망·로딩 중·탑승 중 등 유효하지 않은 사용 요청을 거절합니다.
- 발동 전 거절된 요청에는 재사용 대기를 소비하지 않습니다. 이미 시작된 Double Slash의 중단은 별도로 처리합니다.
- 버프와 재사용 대기는 서버 메모리에서 관리합니다. 사망·로그아웃 시 버프를 해제하고, 캐릭터별 재사용 대기는 재접속으로 초기화되지 않습니다. 서버 재시작 시에는 초기화됩니다.
- Guardian Ward와 Radiance의 공개 연출·조명 동기화와 True Aim의 시전자 전용 표식 전송을 구분합니다.
- 현재 통합 결과의 **프로토콜 버전은 76**입니다. 대상 지정 요청, 어빌리티 상태, 단검 타격별 이벤트, Radiance 조명 상태, True Aim 전용 표식과 거리 초과 거절 사유를 지원합니다. 서버·클라이언트 WASM·에이전트 클라이언트를 같은 프로토콜로 빌드해야 합니다.
- 영구 DB 스키마 변경은 없습니다.

기본 `cargo test --workspace --locked` 실행은 기존 NPC idle/chat 테스트 2개에서 5초 제한을 초과했습니다. 이 Windows 환경은 테스트용 빈 포트 `127.0.0.1:9`에 대한 연결 거절에 약 2초가 걸립니다. 테스트 동안만 해당 주소가 즉시 HTTP 503을 반환하도록 한 뒤, 동일한 워크스페이스 빌드의 에이전트 테스트 바이너리 271개를 모두 통과했습니다. API 불가 조건과 테스트 assertion은 유지했고 코드 수정은 없으며, 임시 서버는 종료했습니다. 나머지 워크스페이스는 `cargo test --workspace --exclude agent-client --locked`로 통과했습니다. 기본 Windows 환경의 전체 워크스페이스 통과를 의미하지 않습니다. 이후 같은 코드 커밋 `3d17717c`의 Ubuntu CI에서는 별도 임시 서버 없이 표준 전체 워크스페이스 명령이 통과했습니다.
