# Auscultation (청진)

모든 직업에 기본 제공하는 장비 조건부 액티브 스킬이다. 별도 숙련도나 경험치는 없다.

청진기는 고블린(`goblin`), 홉고블린(`hobgoblin`), 잊힌 망자(`skeleton_weak`)에게서만 처치당 각각 0.04% 확률로 드롭된다. 필수 장비가 아닌 선택적인 재미 요소이며, 기존 전리품과 독립적으로 추첨한다.

- `stethoscope`를 목 슬롯(`neck`)에 장착해야 한다. 가방에 소지하는 것만으로는 사용할 수 없다.
- 청진기를 장착하지 않았으면 채팅과 토스트에 `You need a stethoscope.`를 표시한다.
- Character → Skills에서 청진기 아이콘을 1–0 퀵슬롯으로 드래그한다.
- 퀵슬롯을 클릭하거나 단축키를 누른 뒤 플레이어·몬스터를 좌클릭한다. 대상 선택 클릭은 공격·이동으로 처리하지 않는다.
- 빈 바닥을 클릭하면 대상 선택을 유지한다. Esc, Cancel 또는 같은 스킬을 다시 누르면 취소한다.
- 장착 해제 시 대상 선택을 취소하고 퀵슬롯을 비활성화한다. 등록은 유지한다.
- 같은 층, 수평 거리 2m 이내, 장애물로 가로막히지 않은 살아 있는 대상만 조사한다. 사망·탑승·월드 로딩 중에는 사용할 수 없다.
- NPC도 조사할 수 있다. 대상이 연주하거나 앉아 있거나 누워 있어도 사용할 수 있으며, 청진은 대상의 연주·자세를 중단하지 않는다.
- MP·아이템을 소모하지 않는다. 성공 후 재사용 대기시간은 0.8초이며 실패·대상 선택 취소에는 적용하지 않는다.
- 실패 사유는 기존 채팅 안내와 함께 공통 스킬 실패 토스트에도 표시한다. 화면 중앙보다 조금 아래에 빨간 글씨로 2.5초간 표시하며, 연속 실패하면 최신 사유로 교체한다. 클릭을 가로막지 않는다.

결과 창에는 대상 이름, 레벨, 현재/최대 HP, Guard, 장착 장비와 강화 수치를 표시한다. 몬스터는 던전에서 조정된 실제 레벨과 현재 HP를 사용하며, 정의된 무기가 있으면 함께 표시한다. 플레이어 Guard는 장비·활성 버프를 반영한다. 가방·금화 등 소지품 정보는 전송하지 않는다.

결과는 검사 시점의 스냅샷이며 자동 갱신하지 않는다. 창을 옮기거나 닫을 수 있고, Esc로도 닫는다. 검사 결과는 시전자에게만 전달한다.

`UseAbility`의 `auscultation`과 `monster_id` 또는 `target_player_id`로 요청한다. 서버가 장비, 생존 상태, 거리, 층, 장애물, 쿨다운을 검증한 뒤 `InspectionResult` 또는 `AbilityRejected`를 보낸다. 장비 판정과 쿨다운 적용은 서버에서 처리하므로 클라이언트의 비활성화 상태를 우회해도 사용할 수 없다.

스킬 아이콘은 [기존 청진기 아이콘](../assets/items.md)을 재사용한다.
