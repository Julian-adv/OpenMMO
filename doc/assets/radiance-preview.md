# Radiance lighting preview

조명 스킬의 VFX와 토글 동작을 확인하는 독립 프리뷰다. 실제 게임 구현은 [Radiance](../abilities/RADIANCE.md)를 따른다.

- 페이지: `client/radiance-skill-preview.html`.
- 프리뷰 전용 코드: `client/src/previews/radiance-skill.ts`. `radiance-effect.ts`는 게임과 공통으로 사용하는 `client/src/lib/effects/radiance.ts`를 다시 내보낸다.
- 모든 무기 타입에서 사용 가능한 콘셉트다. 무기 선택은 외형 비교용이며 발동을 제한하지 않는다.
- 시전 시작 0~0.62초에 작은 빛 구슬이 몸 주위를 일정 반경으로 한 바퀴 돌고, 0.62~0.8초에 그 자리에서 서서히 사라진다. 몸 안으로 들어가거나 작아지지 않으며, 짧은 입자 잔광도 0.8초에 함께 사라진다. 캐릭터의 방향과 이동을 따라 도는 프리뷰 전용 VFX다.
- 유지 중에는 구슬·후광·입자를 표시하지 않고 주변 조명만 시전자를 따라간다. 실제 주변 조명의 강도·거리·감쇠는 그대로 유지한다. 눈에 보이지 않는 PointLight의 높이는 기존 횃불 기준으로 유지한다.
- 횃불을 대체하는 토글형 버프다. 모든 무기에서 사용 가능하며 켠 시점부터 120초 지속한다. 켜기·끄기 각각 사용한 시점부터 0.8초의 재사용 대기시간을 적용한다. 끄기와 만료 시 버프가 해제되고, 다시 켜면 120초를 새로 시작한다. 자연 만료에는 추가 대기시간을 부여하지 않는다.
- 조명은 `torchFlicker.ts`의 기존 횃불 상수를 재사용한다. 기본 강도 50, 감쇠 1.2, 광원 거리 한계 50m이며 후자는 일정 밝기를 보장하는 반경이 아니다. 횃불의 거리별 감쇠를 그대로 사용한다. 밝기 100%가 횃불 기준이며 색과 밝기는 시각 비교용으로 조절할 수 있다. 스킬 이름은 가칭이다.
- 발동 연출 0.8초는 지속시간에 포함한다. 만료 전 마지막 1.2초에 서서히 어두워져 정확히 120초에 꺼진다. 수동 해제 시 버프 표시는 즉시 꺼지고 당시 위치와 밝기에서 1.2초 동안 잦아든다.
- 실제 PointLight로 바닥·캐릭터·소품을 비추고 그림자를 만든다. 시전 구슬의 빛 번짐과 짧은 입자 잔광은 CanvasTexture와 Three.js 도형으로 표현한다. 퍼져나가는 지면 파동은 사용하지 않는다.
- `빛 켜기 / 빛 끄기` 토글, 남은 버프 시간과 ON/OFF 상태를 표시한다. 재사용 대기 중 토글 버튼에 남은 시간을 표시하고 비활성화하며, 입력 처리에서도 연속 전환을 막는다. 대기시간은 연출과 같은 프리뷰 시계를 사용해 일시정지·느린 재생·스크럽과 함께 움직인다. 자동 반복은 하지 않는다. 프리뷰 전용 `시전 다시 보기`는 대기 여부와 관계없이 켜는 연출을 처음부터 재생한다.
- `어둠과 비교`는 버프 상태를 유지하면서 조명과 VFX만 감춰 비교한다. 시간 스크럽·일시정지·느린 재생을 지원하며 `만료 직전 보기`는 117초로 이동해 만료를 시연한다. 스크럽은 수동 해제 기록을 초기화해 정상적인 120초 시전을 탐색한다.

## Sources

- 캐릭터, 전투 대기·걷기 애니메이션, 무기, 나무, 강돌, 상자 및 cobblestone 재질은 기존 프로젝트 에셋을 재사용한다. 원래 출처는 해당 `doc/assets/` 문서를 따른다. 애니메이션 리타게팅과 무기 부착은 기존 유틸리티를 사용한다.
- 빛 VFX와 프리뷰의 단순 기둥 형상은 OpenAI Codex로 작성한 절차적 도형·텍스처다. 작성일 2026-09-13, workspace-provided tier(정확한 등급은 도구에서 공개되지 않음). 프로젝트용 원본 코드이며 별도의 외부 이미지 에셋은 추가하지 않았다.
- 맵 데이터와 기존 에셋을 재생성하지 않는다. 이 프리뷰 페이지 자체는 게임 스킬 판정·네트워크·HUD에 연결하지 않는다.
