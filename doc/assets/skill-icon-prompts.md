# 스킬 아이콘 생성 프롬프트

기준 스타일: **검은 배경 위에 은백색 빛의 붓선으로 그린 고전 판타지 RPG 스킬 아이콘.**

현재 기준 이미지는 Double Slash에 적용한 아래 이미지다. 새 아이콘을 생성할 때 이 파일을 함께 첨부하고, 고정 스타일은 유지한 채 스킬 정보만 바꾼다. 텍스트만 사용하는 것보다 붓선, 색감, 빛 번짐을 맞추기 쉽다.

![Double Slash 스타일 기준](../../client/public/icons/skills/dagger-double-slash-v2.png)

- 기준 파일: `client/public/icons/skills/dagger-double-slash-v2.png`
- [이전 시안](../images/skills/dagger-double-slash-v1.png)은 스타일 참고용으로 보관한다. 현재 아이콘은 퀵슬롯 가독성을 위해 잔선을 줄이고 두 궤적과 단검을 크게 정리한 버전이다.
- 생성일: 2026-09-13
- 생성 도구: OpenAI Codex built-in ImageGen, workspace-provided tier (정확한 등급은 도구에서 공개되지 않음).
- 출처와 사용 기록: [UI Assets](ui.md#skill-icons).

## 복사해서 사용하는 공통 프롬프트

아래 프롬프트와 기준 이미지를 함께 전달한다. 대괄호 안의 스킬 정보만 새 스킬에 맞게 바꾼다.

```text
첨부 이미지를 스타일 기준으로 사용해,
같은 게임의 아이콘 세트에 들어갈 새로운 스킬 아이콘을 만들어줘.
기준 이미지의 소재를 복제하지 말고, 붓선과 빛의 표현 방식을 유지해줘.

[스킬 정보]
- 이름: [스킬 이름]
- 핵심 행동: [어떤 행동을 하는 스킬인지]
- 주요 소재: [무기, 방패, 손, 마법 문양 등]
- 구도: [소재와 효과의 배치, 방향, 개수]

[고정 스타일]
고전 판타지 MMORPG의 작은 래스터 스킬 아이콘.
검은 배경 위에 은백색에서 옅은 아이보리 범위의 단색 빛으로 그린다.
픽토그램처럼 간결하게 읽히면서, 손으로 그린 빛의 붓선과 짧은 잔광으로
약간의 깊이와 섬세함을 표현한다.

- 형태는 날카롭게 뻗는 빛의 붓선과 간결한 붓 자국으로 묘사한다.
- 붓선의 굵기, 겹침, 밝기 차이로 최소한의 깊이감을 표현한다.
- 중심 붓선은 밝고 선명하게, 주변 잔광은 옅고 부드럽게 처리한다.
- 선 사이에 검은 빈 공간을 남겨 형태가 뭉개지지 않게 한다.
- 붓선 가장자리는 약간 불규칙하고, 끝은 가늘고 날카롭게 끊는다.
- 외곽에만 짧게 퍼지는 은은한 글로우와 부드러운 번짐을 넣는다.
- 칼날이나 궤적에 어두운 면을 따로 칠하지 않는다.
  깊이감은 밝은 선의 겹침과 선 사이의 어두운 여백으로 만든다.
- 핵심 요소 1~3개에 집중하고, 주요 형태 사이에는 충분한 검은 여백을 둔다.
- 실제 표시 크기는 40px 퀵슬롯 안의 약 38px다. 36px에서도 핵심 실루엣이 남게 한다.
- 주된 궤적은 두꺼운 중심선을 남기고 잔선을 줄인다. 가장 넓은 부분은
  아이콘 폭의 약 8~12%가 되도록 하여 축소해도 끊어지지 않게 한다.
- 단검 같은 보조 소재도 작은 크기에서 알아볼 수 있게 크고 간결하게 그린다.
- 정사각형 검은 배경, 중앙 배치, 사방에 약 5~7% 여백을 둔다.
  형태를 크게 배치하되 외곽의 짧은 빛 번짐이 잘리지 않게 한다.

[제외할 표현]
- 두꺼운 베벨, 돌출된 테두리, 밝은 면과 어두운 면으로 나뉜 입체적 면 분할.
- 사실적인 금속 광택, 플라스틱 같은 3D 렌더링, 깊은 그림자.
- 두껍고 매끈한 리본 모양의 공격 궤적.
- 넓은 면을 채우는 금속, 대리석, 불꽃 질감.
- 화면 전체 블러, 넓은 흰색 광휘, 과도한 입자와 장식.
- 여러 색의 혼합, 진한 노랑이나 금색, 파랑이나 청록색 강조.
- 글자, 숫자, 배지, 프레임, 워터마크, 배경 풍경.
- 인위적인 픽셀 격자 효과.

첨부 이미지의 붓선, 빛 번짐, 색감과 표현 밀도를 유지하되,
소재와 구도는 새 스킬에 맞게 구성해줘.
결과는 아이콘 한 개만 출력해줘.
```

## 예시 1: Double Slash

공통 프롬프트의 `[스킬 정보]`를 다음 내용으로 바꾼다. 두 번 공격한다는 의미는 두 개의 주된 궤적 묶음으로 표현한다.

```text
[스킬 정보]
- 이름: Double Slash (단검 2연격)
- 핵심 행동: 단검으로 빠르게 두 번 연속 베기.
- 주요 소재: 간결한 단검 하나와 두 개의 뚜렷한 베기 궤적.
- 구도: 아래쪽에는 오른쪽 아래를 향하는 단검을 간결한 선으로 배치한다.
  그 위에는 길고 날카롭게 뻗는 두 베기 궤적을 검은 여백으로 구분한다.
  궤적이 겹치더라도 중앙이 하나의 흰 덩어리로 뭉치지 않게 한다.
  각 궤적은 하나의 주된 붓선 묶음으로 읽히게 하고,
  보조 잔선은 각 묶음에 붙여 정확히 두 번의 공격으로 보이게 한다.
  단검은 얇은 칼날 윤곽, 짧은 가드, 몇 개의 손잡이 선으로 알아볼 수 있게 한다.
  숫자 2나 ×2 표기는 넣지 않는다.
```

## 예시 2: 방패 강타

```text
[스킬 정보]
- 이름: 방패 강타
- 핵심 행동: 방패로 적을 강하게 가격한다.
- 주요 소재: 방패 하나와 짧은 충격 궤적.
- 구도: 중앙에 비스듬히 기울어진 방패를 빛나는 외곽 붓선으로 표현한다.
  방패 앞쪽으로 짧고 날카로운 충격의 붓선이 터져 나온다.
  방패 면은 검은 여백을 넉넉히 남기고, 내부 구조는 몇 개의 선으로만 암시한다.
  별 모양 폭발 장식이나 적 캐릭터는 넣지 않는다.
```

## 수정 요청 문구

원하는 부분만 골라 기준 이미지와 함께 전달한다.

- 더 밝게: `중심 붓선만 더 밝고 선명하게 해줘. 주변 잔광의 범위는 유지해줘.`
- 더 부드럽게: `주요 형태의 선명함은 유지하고, 외곽 빛 번짐만 조금 부드럽게 해줘.`
- 입체감이 과할 때: `칼날과 궤적의 면 분할과 어두운 패널을 없애줘. 선의 겹침과 검은 여백으로만 깊이를 표현해줘.`
- 너무 복잡할 때: `작은 입자와 보조 잔선을 줄이고, 핵심 실루엣과 주된 궤적만 남겨줘.`
- 너무 평평할 때: `붓선의 굵기와 밝기에 작은 차이를 주고, 겹치는 중심선만 밝게 해줘. 베벨이나 금속 음영은 추가하지 마.`

`명암을 진하게`, `고급 금속 재질`, `3D 아이콘` 같은 표현은 면 분할이나 사실적인 재질을 유도할 수 있으므로, 빛나는 선과 잔광 중 어느 부분을 조정할지 구체적으로 적는다.

## 적용 확인

- [Double Slash 가독성 개선에 사용한 실제 영문 프롬프트](dagger-icon-refinement-prompt.txt).
- 스킬 목록과 퀵슬롯의 실제 크기에서 핵심 행동이 읽히는지 확인한다.
- 두 번 공격하는 스킬은 작은 크기에서도 주된 궤적 두 개가 구분되어야 한다.
- 가장자리 빛 번짐이 잘리지 않도록 여백을 유지한다.
- 브라우저에서는 `image-rendering: auto`를 사용해 부드러운 가장자리를 유지한다.
- 새로 채택한 이미지의 출처, 생성 도구와 등급, 생성일을 `doc/assets/ui.md`에 기록한다.
