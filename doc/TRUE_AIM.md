# True Aim

Bow 전용 대상 지정 어빌리티. ABILITIES에서 아이콘을 기존 퀵슬롯에 끌어 놓고 사용한다. 마우스 오버 중인 살아 있는 몬스터를 우선하고, 없으면 현재 지정된 유효 공격 타겟에게 발동한다. 둘 다 없으면 발동하지 않는다. 몬스터 위에 커서를 올리고 단축키를 누르면 클릭 없이 먼저 표식을 걸 수 있다.

- ID: `bow_mark`
- 발동 조건: 살아 있고 로딩이 끝난 캐릭터, 비탑승, 주무기 Bow, 살아 있는 몬스터 대상.
- 사거리: 장착한 Bow의 `weapon_range()` 값(현재 10m), 같은 층, 원거리 시야 검사 통과.
- 지속 5초, 재사용 대기시간 10초. 실패하면 대기시간을 소비하지 않는다.
- 스킬의 대상 선택은 일반 공격·자동 추적을 시작하지 않는다. 마우스 오버 대상이 사거리 밖이거나 장애물에 가려져 있으면 발동만 실패하고, 그 대상으로 달려가지 않는다.
- 사거리 초과 시 `Target is too far away.` 로그를 표시하며 표식과 쿨타임을 적용하지 않는다.
- 대상 지정형 버프·디버프는 어빌리티의 `target: 'monster'` 설정으로 이 선택 규칙을 공유한다. Double Slash처럼 다음 기본 공격을 대체하는 공격 스킬은 기존 예약 방식을 유지한다.
- 시전자 본인의 해당 대상 공격만 반드시 명중한다. 피해 주사위, 화살 피해, 능력치·강화 보너스는 기존 계산을 따른다. 피해 배율이나 치명타 효과는 없다.
- 공격할 때의 사거리·장애물·층·생존·화살·공격 간격 검사는 그대로 적용된다. 시전 자체는 화살을 소비하지 않는다.
- 발동 후 무기를 바꿔도 남은 5초 동안 해당 대상에 대한 본인의 공격에 적용된다. 다른 대상을 공격하면 일반 명중 판정이다.
- 대상 사망·제거, 시전자 사망·접속 종료·층 변경, 지속시간 종료 시 해제한다. 재접속으로 재사용 대기시간을 초기화할 수 없다.
- `BowMarkUpdate`는 시전자에게만 전송한다. 대상 ID는 공개 Player/Monster 스냅샷과 주변 방송에 포함하지 않는다. 실제 공격 결과는 기존 전투 방송을 따른다.
- VFX: `#ed9984` 옅은 붉은빛, 프리뷰 기준 크기 75%, 0.42초 조준 수렴, 1.2초 주기로 ±10% 크기 변화, 종료 시 0.4초 사라짐. 종료 잔상 동안 명중 효과는 없다.

프리뷰와 게임은 `client/src/lib/effects/bow-mark.ts`의 같은 효과를 사용한다. 게임에서는 실제 모델 높이에 맞춰 머리 위 위치를 계산한다. [프리뷰](assets/bow-mark-preview.md), [아이콘 생성 프롬프트](assets/true-aim-icon-prompt.txt).
