# 영구 아이템 번호

아이템의 `instance_id`는 생길 때 한 번 매기고 바뀌지 않는다(결정 2026-11-27). 트로피 기록처럼 아이템 하나에 이어 붙는 기록과, 로그 조사에서 한 아이템이 어디서 와서 어디로 갔는지 따라가는 데 쓴다.

## 발급

- 1부터 메모리에서 1씩 올린다. 마지막으로 매긴 번호를 32초마다 도는 저장 때 `item_id_counter`에 적는다.
- 서버가 뜰 때 그 번호와 아래 표들에 저장된 가장 큰 번호 중 큰 쪽 다음부터 이어 간다. 적기 전에 서버가 멈춰도, 그 사이 번호를 가진 아이템이 저장됐다면 표에서 잡히고, 저장되지 않았다면 아이템도 사라졌으니 겹칠 대상이 없다.

## 저장

| 자리 | 열 |
| --- | --- |
| 가방·착용 | `character_items.item_id` |
| 영지 창고 안 | `estate_chest_items.item_id` (겹치지 않는 아이템만) |
| 벽·바닥에 놓은 가구 | `estate_chests.item_id` |
| 경비대 압수품 | `guard_impound_goods.item_id` (번호가 있으면 합치지 않음) |
| 트로피 기록 | `estate_defense_trophies.item_id` |

땅에 떨어진 아이템은 메모리에만 있고, 번호를 그대로 들고 있다.

## 번호를 지키는 이동

겹치지 않는 아이템 한 개가 옮겨 갈 때 번호가 따라간다: 가방 저장과 읽기, 가구 걸기와 떼기, 창고 넣기와 빼기, 땅에 버리기와 줍기, 플레이어 거래, 노점 판매, 압수와 되찾기.

새 번호가 생기는 곳: 처치·상자·채집 전리품과 몬스터가 떨군 무기, `/give`, 상점 구매, 경비 근무 장비 대여, NPC 옷 건네기, 상인에게 팔기와 되사기(상인 쪽에서 번호가 끊긴다), 울타리·집 문서처럼 세상에 녹아든 아이템을 되돌려 받기.

## 겹치는 아이템

물약처럼 겹치는 아이템은 번호가 더미의 번호다. 합쳐지면 받는 쪽 번호가 남고, 나뉘면 새 번호가 생긴다. 하나하나를 구별하지 않는다.
