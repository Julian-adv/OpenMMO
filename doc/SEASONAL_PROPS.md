# 계절 장식

현실 달력의 특정 기간에만 월드에 서는 장식. 첫 장식은 앨더마크 광장의 겨울 나무다.

## 표

`data-src/seasonal_props.csv` 한 줄이 장식 하나다.

| 열 | 뜻 |
|---|---|
| `id` | 장식 id. 정렬 순서가 배치 id를 정하므로 한번 정하면 바꾸지 않는다. |
| `object` | `data/object_catalog.json`의 오브젝트 id |
| `x`, `z`, `rotation` | 월드 좌표와 회전(도). 높이는 서버가 부팅 때 지형에서 읽는다. |
| `startMonth`, `startDay` | 서는 첫날 (포함) |
| `endMonth`, `endDay` | 서는 마지막 날 (포함). 시작보다 앞이면 해를 넘긴다. |

현재 행: `winter_tree_aldermark`, (-1467, 4752), 12월 10일 ~ 1월 5일.

## 동작

- 날짜는 서버 시계의 UTC 날짜다. 게임 내 달력과 무관하다.
- 서버는 부팅 때와 매시간 날짜를 확인한다. 기간에 들거나 벗어난 장식이 있으면 그 리전의 충돌을 다시 계산한다.
- 기간 안의 장식은 필드 보스 제단과 같은 고정 배치로 들어간다. 리전 오브젝트 파일에 저장하지 않고,
  `GET /api/terrain/objects`가 `fixed: true`로 덧붙여 내려보내며, 에디터 저장(`PUT`)은 이를 걸러낸다.
- 배치 id는 `FIXED_PLACEMENT_ID_BASE`(20억) + 1억부터다. 필드 보스 id와 겹치지 않는다.
- 클라이언트는 리전을 읽을 때 장식을 받는다. 접속 중에 기간이 바뀌면 그 리전을 다시 읽을 때 반영된다.

## 겨울 나무 (`winter_tree`)

- 모델은 `client/public/models/objects/winter_tree.glb`. 높이 5.1m, 가지가 땅까지 내려오는 전나무에 금빛 장식 줄·구슬·별이 달리고
  밑에는 붉은 치마 천 위로 선물 상자가 쌓였다.
  출처와 가공은 [props.md](assets/props.md)에 있다 (David Montaña, CC BY 4.0).
- 카탈로그의 `glow: "winterTree"`가 나무를 꾸민다 (`client/src/lib/utils/winter-tree.ts`).
  - 전구 70개의 색 빛무리. 밝은 띠가 나선으로 나무를 타고 오른다.
  - 꼭대기 별의 옅은 빛무리와 천천히 흔들리는 십자 광채. 처음 세기는 과하다는 평이라 절반 아래로 낮췄다 (사용자 확인 2026-11-24).
  - 가지 위에서 잠깐씩 반짝이는 광채 18개, 나무 둘레로 천천히 가라앉는 금가루 28개.
  - 별과 구슬은 밤에 제 색으로 빛난다 (재질 발광).
  - 밤에는 나무가 주변 바닥과 캐릭터에 따뜻한 빛을 던진다. 지상에서 쉬는 수정 빛 풀의 조명을 빌려 써서
    장면의 조명 수는 늘지 않는다 (`GameScenePlayersLayer.svelte`의 `TREE_GLOW`). 횃불 효과를 끈 그래픽 설정에서는 꺼진다.
  - 모두 셰이더 시간으로 움직여서 프레임마다 도는 스크립트가 없다. 드로콜은 5회 늘고, 밤에 진하고 낮에 옅다.
- 선물 더미를 덮는 2.8m 사각형이 통행을 막는다. 치마 천 가장자리는 밟고 지나간다.

## 장식 추가

1. 오브젝트를 카탈로그에 등록한다. 통행을 막으려면 `solid`를 준다. `footprint`를 함께 주면 모델 경계 상자 대신 그 범위만 막는다.
2. `data-src/seasonal_props.csv`에 행을 추가한다.
3. 좌표는 운영 서버의 실제 배치를 기준으로 확인한다. 마을 건물은 리전 데이터라 저장소에 없다.
