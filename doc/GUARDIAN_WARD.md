# Guardian Ward (검의 수호)

Sword 또는 Mace를 주무기로, Shield를 보조 손에 장착하면 사용하는 파티 방어 버프다.

- 시전자 및 시전 순간 같은 층에서 20 m 이내에 있는 살아 있는 파티원에게 적용한다. 파티가 없어도 자신에게 적용된다.
- 지속 60초, 재사용 45초. 자원 소모는 없다.
- 기본 Guard + 착용 장비 Guard + 방어구 강화 보너스의 합에 10%를 더한다. 정수 능력치이므로 추가량의 소수점은 버린다. 예: 31 → 34, 48 → 52.
- 같은 버프를 다시 받으면 남은 시간을 60초로 갱신하며, 여러 시전자가 사용해도 중첩되지 않는다.
- 시전 후 범위를 벗어나거나 장비를 교체해도 남은 버프는 유지된다. 교체된 장비의 현재 Guard를 기준으로 계산한다.
- 사망·로그아웃 시 버프가 해제된다. 재사용 대기시간은 캐릭터별로 서버 메모리에 보관하여 재접속으로 초기화되지 않는다. 서버 재시작 시 버프와 재사용 대기시간은 초기화된다.

## 사용 및 표시

- 캐릭터 창 **ABILITIES**의 아이콘을 기존 퀵슬롯(1–0)으로 드래그하고, 슬롯 또는 숫자 키를 눌러 즉시 사용한다.
- 기존 인벤토리 포인터 드래그 코드를 공유한다. **SKILLS**는 낚시 등 기존 숙련 스킬 목록을 유지한다.
- 현재 액티브 스킬처럼 별도의 습득 조건 없이 표시된다. 아이콘에 마우스를 올리면 효과와 장착 조건, 시간 정보가 나온다.
- 장비 조건을 만족하지 않으면 퀵슬롯 검사와 서버 거절 응답 모두 공통 `Cannot use {스킬명}.` 메시지를 표시한다.
- **ABILITIES**와 퀵슬롯은 공용 기술 툴팁을 사용한다. 인벤토리 설명의 색상·글자 크기를 따르고, 이름·설명 아래에 효과·장착 조건·시간 정보를 항목별로 정렬한다. 기술 정의의 `stats`와 보충 설명 `details`를 표시하므로 다른 액티브·패시브 기술에도 같은 형식을 사용할 수 있다.
- 퀵슬롯에는 재사용 대기시간, 좌측 상단 레벨·허기 상태 옆에는 적용 중인 버프 아이콘과 남은 시간이 표시된다. 버프 아이콘에 마우스를 올리면 효과를 확인하고, 클릭하면 **STATUS**에서 상세 상태를 볼 수 있다. 만료·사망·로그아웃 시 표시가 사라진다. 실제 Guard 수치는 서버에서 전달한다.
- 상단 버프 툴팁에는 이름과 효과만 표시한다. **STATUS**의 한시적 버프는 기본 상태 정보 아래에 배치하여 만료 시 기본 정보의 위치가 움직이지 않게 한다.
- 다른 작업 브랜치에서 저장된 퀵슬롯 바인딩은 유지한다. 현재 빌드에 등록되지 않은 스킬은 표시·발동하지 않는다.

## 판정 및 네트워크

- `weaponType=sword|mace` 및 실제 off-hand 장비의 `armorType=shield`를 서버에서 확인한다. Torch는 방패로 인정하지 않는다.
- Goblin Sword 및 Small Sword는 Sword로 분류한다. Dagger와 Great Sword는 별도 분류다. 이 분류 변경은 `d24b0b16`에 기록했다.
- 서버가 적용 대상, Guard, 지속시간과 재사용 대기시간을 관리한다. 사망/로딩 중 사용 요청은 거절하고, 실패한 요청은 재사용 시간을 소비하지 않는다.
- 통합 프로토콜 v76: `UseAbility`, `AbilityCooldowns`, `BuffUpdate`, `AbilityRejected`, `AbilityUsed` 및 Double Slash·Radiance·True Aim 메시지를 함께 지원한다. 서버·클라이언트 WASM·에이전트 클라이언트를 함께 빌드해야 한다.

## 표현

- 옅은 금빛의 방패 문양이 시전자와 적용 대상 앞에 동시에 나타난다. 확산 파동과 거리별 도착 지연은 없다.
- 1초 효과음의 시작 타격에 맞춰 즉시 나타나고, 약 0.14–0.15초에 작은 두 번째 크기 변화와 중심 섬광을 사용한다. 0.35초부터 잦아들어 1초에 사라진다. 방사형 빛 조각이나 머리 위로 이동하는 문양은 없다.
- 발동 연출은 1초, 실제 버프는 60초다. 시전자는 이동할 수 있으며 대상 문양은 보이는 캐릭터를 따라간다. 기존 동작 애니메이션을 유지한다.
- 프리뷰와 게임에서 같은 `SwordGuardEffect`를 사용한다. VFX 출처: [sword-guard-preview.md](assets/sword-guard-preview.md).
- 게임에서는 서버 발동 이벤트에 맞춰 방패 버프 효과음을 한 번 재생한다. 같은 층의 시전자 20 m 이내에서 들리며, 파티에 속하지 않은 주변 유저도 들을 수 있다. 기존 효과음 볼륨·음소거 설정을 따른다. [효과음 출처](assets/sfx.md#abilities).
- 아이콘은 기존 Double Slash 생성 프롬프트 및 기준 이미지의 빛나는 붓선 스타일을 사용한다. [실제 생성 프롬프트](assets/guardian-ward-icon-prompt.txt), [이미지 출처](assets/ui.md).
