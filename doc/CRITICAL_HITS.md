# 치명타와 균열의 반지

결정·구현일: 2026-10-25. 관련 설계: [전투](COMBAT.md), [인챈트](ENCHANT.md), [테라클래시 보상](TIER5_FIELD_RAID.md#증표-교환과-장비-공급량).

## 확정 규칙

| 항목 | 규칙 |
| --- | --- |
| 플레이어 기본 치명타 확률 | 레벨·무기와 관계없이 5% |
| 치명타 판정 | 기존 명중 판정을 통과한 뒤 독립적으로 판정 |
| 치명타 피해 | 능력치·무기 강화·탄약까지 포함한 일반 피해의 2배 |
| 적용 공격 | 플레이어 기본 공격과 Double Slash의 각 타격. 근접·원거리 모두 적용 |
| 명중 주사위 | 기존 폭발 d20 유지. 자연 20이 자동 명중이나 치명타를 보장하지 않음 |
| 균열의 반지 | 치명타 확률 +5%p, 착용 시 총 10% |
| 동일 반지 두 개 | 양손 착용 가능. 효과는 한 번만 적용하여 총 10% |
| 교환 | 이졸데에게 테라클래시 파편 30개로 반지 1개. 기존 CHA 흥정 적용 |
| 기타 수치 | 무게 0.1, 기준가 30,000, 일반 거래 가능. 상자·직접 드롭 없음 |
| 상태창 | 서버가 계산한 현재 치명타 확률을 표시. 장착·해제 시 갱신 |
| 전투 표시 | 치명타 로그, 금색 피해 숫자와 느낌표 |

## 뒤치기 첫 타

결정·구현일: 2026-11-05.

| 항목 | 규칙 |
| --- | --- |
| 조건 | 전투 중이 아닌 몬스터(목표 플레이어가 없고 추격·대기·공격 상태도 아님)를 등 뒤에서 공격 |
| 뒤쪽 범위 | 몬스터가 바라보는 방향의 정반대 기준 ±45°(90° 부채꼴). 몬스터 중심에서 공격자 위치로 판정 |
| 효과 | 명중하면 치명타 확률 100%. 명중 굴림은 그대로이며 빗나가면 그냥 빗나감 |
| 적용 공격 | 모든 몬스터, 플레이어 공격 판정 전체(근접·원거리·Double Slash·발할라 돌진). 원거리는 쏜 위치 기준 |
| 한 번만 | 공격받은 몬스터는 빗나가도 공격자를 목표로 잡으므로 이후 타격·다른 파티원의 뒤치기에는 적용되지 않음 |

사거리 밖 헛스윙(10m 이내)도 몬스터를 깨우므로 기회를 잃는다. 선공형 몬스터의 감지는 방향을 보지 않으므로 감지 범위 안에서는 등 뒤로 돌아갈 수 없다.

몬스터 공격·보스 기술·환경 피해에는 이번 플레이어 치명타를 적용하지 않는다. 공격 속도와 사거리, 방어력 계산은 기존 규칙을 따른다. 성공한 공격의 최소 피해 1을 정한 뒤 치명타 배율을 적용한다.

## 보상 가치와 강화 비교

기본 치명타가 5%, 피해 배율이 2배이면 일반 명중 피해 `D`의 평균은 `D × 1.05`다. 반지로 10%가 되면 `D × 1.10`이므로, 기대 피해는 기존 대비 약 **4.76%** 증가한다. 치명타 확률 +1%p는 같은 조건에서 약 **0.95%** 증가에 해당한다.

무기 강화 한 단계는 피해 +1뿐 아니라 명중 굴림도 +1을 준다. 따라서 치명타와의 가치는 현재 피해량·상대 방어력에 따라 달라진다. 강화 전후 명중률을 `p`, `p'`, 일반 명중 평균 피해를 `D`, `D'`라 하면 강화 한 단계와 같은 총 치명타 확률 `c`는 다음과 같다.

```text
p × D × (1 + c) = p' × D' × 1.05
c = 1.05 × (p' / p) × (D' / D) - 1
추가 치명타 확률 = c - 0.05
```

최소 피해 보정이 걸리지 않으면 `D' = D + 1`이다. 명중률의 변화는 폭발 d20에서 실제 상대 방어력으로 계산하며, 항상 5%p가 오르는 것은 아니다.

| 현재 일반 명중 평균 피해 | 명중률 100% 유지 시 필요한 추가 확률 | 강화로 명중률 70% → 75%일 때 |
| --- | ---: | ---: |
| 5 | +21%p | +30%p |
| 10 | +10.5%p | +18.75%p |
| 15 | +7%p | +15%p |
| 20 | +5.25%p | +13.125%p |

### 50레벨·힘 16·강철 장검 +9 예시

디버프 없음, 힘 보정 +3, 무기 피해 1d10을 가정한다. +9검의 일반 피해는 `1d10 + 12`, 평균 17.5이며 명중 보너스는 `25 + 3 + 9 = 37`이다.

| 장비 | 확정 명중 상대의 공격당 기대 피해 | 테라클래시(guard 43)의 공격당 기대 피해 |
| --- | ---: | ---: |
| +9검, 치명타 5% | 18.375 | 12.8625 |
| +9검·균열의 반지, 치명타 10% | 19.25 | 13.475 |
| +10검, 치명타 5% | 19.425 | 14.56875 |

테라클래시에게 +9검의 명중률은 70%, +10검은 75%다. +9검·반지는 +10검보다 확정 명중 상대에게 약 0.9%, 테라클래시에게 약 7.5% 낮은 기대 피해를 낸다. 이는 힘·상대가 정해진 예시이며 50레벨 캐릭터 전체의 고정값은 아니다.

파편 30개는 매번 3개를 받으면 10회, 2개면 15회, 1개면 30회 토벌로 모은다. 고강화 실패 위험 없이 누적 참여로 얻는 보상이므로 강력한 공격 장비지만, 교환 비용은 **30개를 유지**하고 동일 반지 효과 중복을 막기로 했다.

## 참고한 게임의 방식

- D&D 5판·2024 개정: 명중 굴림 자연 20이면 자동 명중·치명타. 피해 주사위 개수를 두 배로 하며 고정 보너스는 한 번 더한다. [공식 규칙](https://www.dndbeyond.com/sources/dnd/br-2024/playing-the-game#CriticalHits)
- NetHack 3.6.7: 일반적인 모든 무기의 치명타 능력치보다 Vorpal Blade의 참수, Tsurugi of Muramasa의 양단·큰 적 상대 2배 피해 같은 아티팩트 특수 효과가 있다. [공식 구현](https://github.com/NetHack/NetHack/blob/NetHack-3.6.7_Released/src/artifact.c#L1170-L1261)
- WoW: 장비·특성으로 치명타 확률을 높이는 방식과 피해 배율을 참고했다. 구체적인 배율은 판본·특성·PvP에 따라 다르다. [개발자 설명](https://worldofwarcraft.blizzard.com/en-us/news/2633773/dev-watercooler-critical-hits-and-misses)
- Diablo II: 물리 피해를 두 배로 하는 Critical Strike·Deadly Strike를 참고했다. [공식 가이드](https://classic.battle.net/diablo2exp/items/magic.shtml)
- Diablo III·IV: 확률과 치명타 피해를 별도로 성장시키는 방향도 검토했다. 이번에는 피해 배율을 2배로 고정하고 확률만 장비 효과로 둔다. [Diablo III 장비 예시](https://kr.diablo3.blizzard.com/en-us/profile/Aftermath-3435/hero/86193727), [Diablo IV 공식 설명](https://news.blizzard.com/en-gb/article/24014289/master-your-power-in-season-of-blood)
